# Match input

Extract the competition bundle here or pass its parent directory to `predict.py --data-dir`. The predictor opens the following three files relative to that directory.

```text
tactical/BAR-ATH_tactical_atd.xml
tactical/BAR-ATH_tactical_atd.txt
tactical/BAR-ATH_tactical_smart_tagging.xml
```

Registered participants obtain the bundle from the organizers. Data access and redistribution are governed by the terms accepted at enrollment. [Official asset description](https://github.com/metrica-sports/more-than-a-hack-2027/blob/main/DATA.md)
